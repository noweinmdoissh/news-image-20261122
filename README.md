One image summing up 22 November 2026 in six stories: COP31 ends with no deal, Iran strikes a site in Bahrain, a drone hits the Kyiv region, Mexico captures a cartel boss, US stocks fall into a correction, and the World Court rules on the Rohingya.

The image is 1024x1024 and names the day in its masthead, so a reader who missed the day can still tell what happened.

`main.ts` copies `entry.png` to the output directory. Run it with `MAKEFUN_OUTPUT_DIR=out node main.ts` to check the output locally.
